# work-portfolio

Job search workspace for Taylor Bornstein — a Director-level content/communications
search across remote tech, developer-tools, and AI companies.

- **`CLAUDE.md`** — the durable context file. Work history, the seven screening
  criteria, positioning, recruiter strategy, and working rules. Read this first.
- **`SESSION-NOTES.md`** — running log of what's been built and decided, and the
  current open threads.

Drop resumes, the job-board tracker, the target-company list, and other search assets
in this repo as they're produced; `CLAUDE.md` is written to give Claude Code full
context without re-explaining the background each session.
